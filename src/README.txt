PlayGo v0.1.0
囲碁を、楽しく。あなたのペースで一局ずつ。

作成日: 2026-10-18

【始め方】
1. ZIPを右クリックし「すべて展開」します。
2. 展開したPlayGoフォルダー内のPlayGo.exeを開きます。
3. 「新規登録」でプレイヤー名を登録します。
4. 最初は「日本ルール / 9路 / いい勝負 / 先攻」がおすすめです。
5. 「CPUエンジン 準備完了」と表示されたら「対局を始める」を押します。

ZIP内から直接実行せず、書き込みできるフォルダーへ展開してください。
EXEだけを移動せず、engine・profile・licensesを同じフォルダーに置きます。
初回のモデル読み込みは、通常のCPU着手とは別に時間がかかります。
展開後の対局にインターネット接続は必要ありません。

【動作環境】
Windows 11 / 64bit。AI計算はSSE2対応CPUで行い、専用GPUは不要です。
画面表示にはWindowsで動作する内蔵グラフィックスなどを使用します。
開発時の試験機はIntel Core i7-12650H、物理メモリ32GBです。
それより低いCPU・メモリの最低条件はまだ検証していません。
CPU着手の受入条件は画面反映まで5秒以内です。超過や解析失敗は画面で通知します。
エンジンの準備中、画面を閉じても安全に終了できます。

【基本操作】
・自分の番に盤面の交点をクリックすると石を置けます。
・相手の石の上下左右の空点（呼吸点）をなくすと、石を取れます。
・自殺手、直後のコウ取り返し、石のある点には打てません。
・「パス」：打たずに手番を渡します。双方が続けてパスすると採点へ進みます。
・「待った」：直前の自分の着手前へ戻ります。通常は2着手戻り、繰り返せます。
・「対局を中止」：この対局の戦績や棋力調整を記録せず、起動画面へ戻ります。
・目差・勝率はあなた側から見た予測です。黒の推定領域は青、白は赤です。
・解析がまだない局面は「—」「未解析」と表示し、グラフの線をつなぎません。
・「情報」「コメント」で、ルール説明や局面のヒントを切り替えられます。

【ルールとコミ】
コミは先に打つ黒の有利を調整するため、白へ加える点数です。
日本：地と取り石を数え、白へ6.5目を加えます。セキの眼は地に含めません。
中国：盤上の石と地を数え、白へ7.5目を加えます。取り石は別に加算しません。
純碁：最後に盤上にある石数だけを厳密に数えます。コミ0、同数は引き分けです。
純碁の死石は対局中に実際に取ってください。採点時には自動で除去しません。
純碁のCPUと途中の目差・勝率・助言は近似評価です。最終得点には使用しません。
長いコウの循環で同一局面が繰り返される場合は無勝負とし、棋力調整に使いません。

【採点と感想戦】
日本・中国では、死石候補に赤い×が付きます。石の連をクリックして修正してください。
日本では「死石を修正中（切替）」でセキ修正へ切り替えられます。緑の輪がセキ候補です。
死石・セキの候補は自動の確定判定ではありません。内訳を確認して確定してください。
対局を続けたい場合は「待ったで対局へ戻る」を選びます。
確定後は「感想戦」「次のゲーム」「最初の画面」を選べます。
感想戦は一手ずつ、または自動で再生できます。未解析の局面は追加で解析します。
「アドバイス」には比較候補や推定損失が表示されます。感想戦は戦績を変更しません。

【難易度と棋力】
のびのび / いい勝負 / 腕試し / 強敵 / 大挑戦 の5段階です。
同じルール・路数・難易度の直近10局を目安に、次局の強さを調整します。
想定勝数は順に8勝以上 / 6～7勝 / 4～5勝 / 2～3勝 / 0～1勝で、保証ではありません。
強さは対局途中では変わりません。待ったを使って完了した対局も記録します。
段級位はアプリ内の推定値です。公式の段級位とは異なり、起動画面で手動変更できます。
他のルールへの棋力修正は小さくしています。

【保存と復旧】
profileフォルダーに、プレイヤーIDごとのJSONを保存します。名前はJSONの中にあります。
名前を変えても戦績は同じIDに残ります。設定は対局開始時に保存します。
対局結果の要約は最新1000局、通算成績は全期間を保持します。
対局中の棋譜・感想戦はアプリ終了後には復元されません。
JSONの手作業編集は推奨しません。変更前の保存は.bak、削除した情報は.deletedへ退避します。
破損が見つかると起動画面に復旧ボタンを表示し、元の内容を.recoveryへ退避して復元します。
すでに.recoveryがある場合は停止します。アプリを閉じてprofile全体を別の場所へバックアップし、
退避済みファイルを保管してから復旧してください。
保存できない場合は、他のPlayGoを閉じて、フォルダーへの書き込み権限を確認してください。
store.lockが残った場合、全PlayGoと書き込み処理の終了を確認してから、フォルダー全体を
バックアップし、ロックの所有者がいないことを確認して対処してください。
バックアップやPC移動は、アプリを閉じてPlayGoフォルダー全体をコピーしてください。
公開する際は、自分のprofileフォルダーを配布しないでください。

【困ったとき】
起動失敗：ZIPを再展開し、engine/runtimeのkatago.exeとmodel.bin.gzがあるか確認します。
動作環境：Windows 11 / 64bit用です。Windowsのバージョンと展開先を確認してください。
解析失敗：「解析を再試行」を選びます。繰り返す場合は対局を中止してください。
5秒超過：他の重い処理を終了して再試行してください。このPCでは性能条件が未達です。
Windowsの警告：署名していない開発版です。配布元とZIPのSHA-256を確認してください。
セキ・死活の複雑な形は自動提案に誤りがあり得ます。確定前に手動修正してください。
