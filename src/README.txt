NobiGo v0.7.0
囲碁を、楽しく。あなたのペースで一局ずつ。

作成日: 2026-10-18

【始め方】
1. ZIPを右クリックし「すべて展開」します。
2. 展開したNobiGoフォルダー内のNobiGo.exeを開きます。
3. 初回だけネットに接続し、モデルの取得・検証・読込みが終わるのを待ちます。
   取得中は「準備を中止」、失敗後は「準備を再試行」でやり直せます。
4. 「新規登録」でプレイヤー名を登録します。
5. 初期設定は「日本ルール / 9路 / いい勝負 / ランダム」です。
6. 「CPUエンジン 準備完了」と表示されたら「対局を始める」を押します。

ZIP内から直接実行せず、書き込みできるフォルダーへ展開してください。
EXEだけを移動せず、engine・profile・licensesを同じフォルダーに置きます。
モデルはZIPに同梱していません。初回取得にはWindows標準のcurl.exeとインターネット接続が必要です。
取得先・モデル・照合値は固定されています。取得は最大3分、最大256MiBで、失敗時は再試行できます。
モデルの取得・照合と読込みは、通常のCPU着手とは別に時間がかかります。
初回の取得・検証・保存が完了すれば、以後の起動・対局・感想戦にインターネット接続は必要ありません。
正常な保存済みモデルは再取得せず、自動更新もしません。
先攻・後攻の初期選択は「ランダム」です。登録済みプレイヤーを選ぶと、前回保存した選択を引き継ぎます。

【動作環境】
Windows 11 / 64bit。AI計算はSSE2対応CPUで行い、専用GPUは不要です。
画面表示にはWindowsで動作する内蔵グラフィックスなどを使用します。
最低CPU・メモリは未定です。公開する検証記録に測定したPC構成と実測結果を記載します。
測定結果はその環境での結果で、他のPCでの性能は未検証です。
CPU着手の受入条件は画面反映まで7.5秒以内です。超過や解析失敗は画面で通知します。
色分けは解析結果が届いた時点で更新します。試験機での検証上限は4.5秒で、CPU着手を優先します。
エンジンの準備中、画面を閉じても安全に終了できます。

【基本操作】
・画面上部はアプリ名・ルール・盤サイズ・あなたの棋力・CPU難易度の順です。棋力は対局中のルールの値です。
・右上にプレイヤー名と石色を表示します。長い名前は一部省略しますが、石色は残ります。
・自分の番に盤面の交点をクリックすると石を置けます。
・相手の石の上下左右の空点（呼吸点）をなくすと、石を取れます。
・自殺手、直後のコウ取り返し、石のある点には打てません。
・「パス」：打たずに手番を渡します。双方が続けてパスすると採点へ進みます。
・CPUのパスは、画面上部と手数欄に黄色で表示します。
・「待った」：直前の自分の着手前へ戻ります。通常は2着手戻り、繰り返せます。
・「対局を中止」：この対局の戦績や棋力調整を記録せず、起動画面へ戻ります。
・目差・勝率はあなた側から見た予測です。黒の推定領域は青、白は赤です。
・グラフの左軸・緑の実線が目差、右軸・紫の破線が勝率です。縦線は表示中の手です。
・数値は目差・勝率・直前損失の1行です。損失は直前に打った側の値で、純碁では行末に「近似」を付けます。
・色分けは「解析待ち」の後、現在局面の最初の有効な結果から更新します。CPU着手を優先します。
・解析がまだない数値は「—」「未解析」と表示し、グラフの線をつなぎません。
・対局は「コメント」から始まります。「情報」と切り替えられ、選択中のタブには緑の枠が付きます。

【ルールとコミ】
コミは先に打つ黒の有利を調整するため、白へ加える点数です。
日本：地と取り石を数え、白へ6.5目を加えます。セキの眼は地に含めません。
中国：盤上の石と地を数え、白へ7.5目を加えます。取り石は別に加算しません。
純碁：最後に盤上にある石数だけを厳密に数えます。コミ0、同数は引き分けです。
純碁の死石は対局中に実際に取ってください。採点時には自動で除去しません。
純碁のCPUと途中の目差・勝率・比較候補は近似評価です。最終得点には使用しません。
長いコウの循環で同一局面が繰り返される場合は無勝負とし、棋力調整に使いません。

【採点と感想戦】
日本・中国では、死石候補に赤い×が付きます。石の連をクリックして修正してください。
日本では「死石を修正中（切替）」でセキ修正へ切り替えられます。緑の輪がセキ候補です。
死石・セキの候補は自動の確定判定ではありません。内訳を確認して確定してください。
対局を続けたい場合は「待ったで対局へ戻る」を選びます。
確定後の短い演出が終わると「感想戦」「感想戦（概要）」「次のゲーム」「最初の画面」の選択ウィンドウが開きます。
閉じても「次の行動を選ぶ」で再度開けます。感想戦終了後も同じ選択肢へ戻ります。
感想戦は一手ずつ、または自動で再生できます。石の番号はパスを含む着手順です。
取られた石の番号は消え、同じ場所に打った新しい石には新しい番号が付きます。
感想戦は「アドバイス」から始まります。CPUの手は狙いの推定、自分の手は次に学べることを示します。
要約は危険・効果・確認事項を3行以内で表示します。
「詳しく」を押すと、原則4～6文の解説と着目範囲の部分図が開きます。
部分図の横の全体盤では、拡大している範囲を枠で囲みます。対象切替や図の移動に合わせて枠も動きます。
詳細を開いていないときも、感想戦の盤面で同じ範囲を囲みます。閉じた後も範囲を保ち、開き直すと続きから確認できます。
一手戻る・進む・自動再生では、新しい手の着目範囲へ切り替わります。
中央の番号は着手順です。石を選ぶと、上下左右につながった石の集まり（連）を囲みます。
石の内側の輪はAIの生存見込みです。緑＝安定、赤＝注意、灰＝未確定で、生存確率や死活の保証ではありません。
緑の輪は複数の合法な読み筋でも安全を確認した場合だけ表示します。所有予測だけで安定とは判定しません。
同色の石を結ぶ青線は連結済みです。別々の連の間の線はAIによる連絡の推定です。
緑の実線＝攻められても連絡を保つ変化を複数確認、赤の破線＝切断に注意、灰の点線＝読みが足りず未確定です。
対象は共有呼吸点を持つ連で、最大8候補・各16手の読みを使います。すべての攻めを調べ尽くした評価ではありません。
注釈は拡大図の範囲だけに表示します。詳細を閉じた盤面でも同じ範囲に表示し、盤の小さな全体図には重ねません。
選択した連の石数と、図外にある同じ連の石数も表示します。
「前の対象」「次の対象」で説明対象を、「着手前へ」「着手後へ」で前後の盤面を切り替えます。
矢印で部分図を移動し、「選択へ」で選択した石へ戻れます。
石を取った効果と、自分の石もアタリになる危険など、同時に起きたことも説明します。
長文はホイール・上下ボタン・↑↓・PageUp/PageDownで読めます。Home/Endで先頭・末尾へ移動します。
Escまたは「閉じる」で戻ります。詳細を開くと自動再生が止まり、閉じても自動再開しません。
本文と局面は開いた時点の内容です。図のAI推定は解析到着時に更新し、比較候補の本文は開き直すと更新します。
現在と直前の追加解析は感想戦だけで自動実行します。未解析・解析中・失敗は灰色と状態表示で区別します。助言は盤面の効果に基づく説明で、読み筋の完全な解説ではありません。
解析に失敗した場合、自動再生は停止します。「解析を再試行」で再度試せます。
純碁の予測値には「近似」を表示します。感想戦で戦績や棋力を変更することはありません。

【感想戦（概要）】
4ページで「結果とハイライト」「CPUの戦略（推定）」「あなたの良かった場面」「次の一局で試すこと」を振り返ります。
「次のページ」「前のページ」で移動し、最後の「感想戦終了」またはEscで4つの選択肢へ戻ります。
本文は通常の解説と同じ操作でスクロールできます。盤面の赤い輪は実際の着手、青い輪は比較候補です。
確定得点とAIの予測値は別です。純碁のAI評価にも「近似」を表示します。
序盤・中盤・終盤は手数を三等分した目安です。CPUの戦略は実際の取り・救出・連結や着手位置から推定します。
好手・改善場面・ハイライトは解析できた範囲から選び、数手先の結果やCPUの意図は断定しません。
既存の解析を再利用し、不足分を最大12局面・全体60秒まで補います。待機中でもページ移動や終了ができます。
解析不足では理由を表示し、根拠のない好手を作りません。失敗時は「解析を再試行」で再度試せます。
概要の開閉では棋譜・戦績・棋力を変更しません。

【難易度と棋力】
のびのび / いい勝負 / 腕試し / 強敵 / 大挑戦 の5段階です。
同じルール・路数・難易度の直近10局を目安に、次局の強さを調整します。
想定勝数は順に8勝以上 / 6～7勝 / 4～5勝 / 2～3勝 / 0～1勝で、保証ではありません。
強さは対局途中では変わりません。待ったを使って完了した対局も記録します。
段級位はアプリ内の推定値です。公式の段級位とは異なり、起動画面で手動変更できます。
他のルールへの棋力修正は小さくしています。

【保存と復旧】
profileフォルダーに、プレイヤーIDごとのJSONを保存します。名前はJSONの中にあります。
名前を変えても戦績は同じIDに残ります。設定は対局開始時に保存します。
対局結果の要約は最新1000局、通算成績は全期間を保持します。
対局中の棋譜・感想戦はアプリ終了後には復元されません。
JSONの手作業編集は推奨しません。変更前の保存は.bak、削除した情報は.deletedへ退避します。
破損が見つかると起動画面に復旧ボタンを表示し、元の内容を.recoveryへ退避して復元します。
すでに.recoveryがある場合は停止します。アプリを閉じてprofile全体を別の場所へバックアップし、
退避済みファイルを保管してから復旧してください。
保存できない場合は、他のNobiGoを閉じて、フォルダーへの書き込み権限を確認してください。
store.lockが残った場合、全NobiGoと書き込み処理の終了を確認してから、フォルダー全体を
バックアップし、ロックの所有者がいないことを確認して対処してください。
バックアップやPC移動は、アプリを閉じてNobiGoフォルダー全体をコピーしてください。
公開する際は、自分のprofileフォルダーを配布しないでください。

【PlayGoからの引継ぎ】
両方のアプリを終了し、旧版のprofileフォルダー全体を別の場所へバックアップします。
NobiGoのZIPを新しい場所へ展開し、空のprofileへ旧版の内容をコピーします。
プレイヤーID・JSON形式は共通です。既存データ同士を上書き・統合しないでください。
起動後、名前・戦績・前回の設定を確認します。問題があれば旧版とバックアップへ戻せます。

【困ったとき】
初回取得の失敗：接続・空き容量・保存先への書込みを確認し、他のNobiGoを閉じて「準備を再試行」を押します。
モデル破損：「モデルを再取得」を押します。照合が成功するまで既存ファイルは置き換えません。
起動失敗：engine/runtimeのkatago.exeと、初回取得後のmodel.bin.gzがあるか確認します。
curl.exeが利用できない場合はWindowsの管理者へ確認してください。セキュリティ設定を変更して回避しないでください。
取得のロックが残った場合は、全NobiGoの終了と取得処理が動いていないことを確認します。
NobiGoフォルダーをバックアップした上で、engine/runtime/model.lockだけを削除して再試行します。
動作環境：Windows 11 / 64bit用です。Windowsのバージョンと展開先を確認してください。
解析失敗：「解析を再試行」を選びます。繰り返す場合は対局を中止してください。
7.5秒超過：他の重い処理を終了して再試行してください。このPCでは性能条件が未達です。
Windowsの警告：署名していない開発版です。配布元と公開された検証記録のZIP SHA-256を確認してください。
セキ・死活の複雑な形は自動提案に誤りがあり得ます。確定前に手動修正してください。
